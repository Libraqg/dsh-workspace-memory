### 仓库地址
https://github.com/Libraqg/dsh-workspace-memory

### 一句话价值
为 DSH 提供显式、项目级记忆交接：你主动点击“注入记忆”并确认后，才调用一次模型整理旧对话，并在第一条消息后注入；没有后台捕获，也没有静默模型调用。

### 能力分类
记忆与上下文

### 安装命令
dsh plugin --profile web add github:Libraqg/dsh-workspace-memory

Desktop profile：
dsh plugin --profile desktop add github:Libraqg/dsh-workspace-memory

### 兼容与运行要求
DSH >= 0.2.1-rc.2；Node >= 22.19；macOS / Windows / Linux；Web 或 Desktop profile；无原生依赖，无需 build script 审批。

### 许可证
MIT

### 截图 / 演示
README: https://github.com/Libraqg/dsh-workspace-memory#screenshots

MP4: https://github.com/Libraqg/dsh-workspace-memory/blob/main/assets/demo.mp4

### 补充说明
- 只在你确认后调用一次模型；不自动捕获、不自动召回、不自动重试。
- 记忆保存在 ~/.dsh/workspace-memory/，不上传云端；无 telemetry。
- 插件只读取同一项目的旧会话日志，写入 brief/notes/state；没有原生依赖。
- 当前通过 GitHub 源码安装，尚未发布 npm，因此不会出现在 DSH 内置插件中心。
